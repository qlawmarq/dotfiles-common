# レポート書式テンプレート（日本語・構造化）

調査結果は下記の構造で出力する。クエリの複雑度に応じてセクションを増減してよいが、**要約・主要な発見（タグ付き）・確信度と限界・出典**は常に含める。

---

## 標準テンプレート

```markdown
# [調査タイトル]

## 要約
（3〜6行。結論を先に。確からしさ語彙と確信度を併記。判定不能なら正直にそう書く。）

## 調査した問い
- （フェーズ1で定義したサブ質問を列挙）

## 主要な発見
各発見に出典番号と3段階タグを付ける。

1. **[事実]** ……（内容）。〔出典 1, 3〕
2. **[事実]** ……。〔出典 2〕
3. **[推論]** ……（事実1と2から導かれる解釈）。
4. **[未確認/憶測]** ……（裏付けが取れなかったが言及する価値がある点）。

## 異なる見解・対立する情報
（情報源が食い違う点を明示。どちらをどの根拠でどう評価したか。一方に断定できなければ両論併記し確信度を下げる。）

## 確信度と限界
- 全体の確信度：高 / 中 / 低（理由：情報源の量・質・裏付けの強さ）
- 判明しなかったこと／今回の調査で確認できなかったこと（正直に）
- 反証として探したが見つかった/見つからなかった証拠

## 出典
独立性・信頼性が分かる形で列挙。Admiraltyグレードを付してもよい。
1. [媒体名・著者] タイトル. URL（日付）. 〔一次/二次/三次〕〔B2〕
2. ...
```

---

## 書式のルール

- **結論を先に**（要約）。読み手が忙しい前提で。
- **各事実に出典番号**を付け、出典セクションでURLまで辿れるようにする（再現可能性）。
- **タグを省略しない**。[事実]/[推論]/[未確認] の区別がこのレポートの価値。
- **両論併記**: 情報源が対立する論点では、一方を消さず両方を提示し、評価の根拠を述べる。同じ証拠基準をすべての主張に適用する。
- **確信度を明示**し、低い項目はヘッジ表現（「〜の可能性がある」等）を使う。断定口調で不確実を覆わない。
- **判定不能を恥じない**: 「調査したが確認できなかった」は一級の成果として明記する。
- **軽量レベル**では「異なる見解」「確信度と限界」を簡潔に1〜2行に圧縮してよいが、出典とタグは省略しない。
